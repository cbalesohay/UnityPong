# Unity Pong

# Unity Version: 6.5 6000.5.6f1

#### If you want to just play the game

### Downloading the Game:

1. Visit the Unity Pong repository on GitHub. https://github.com/cbalesohay/UnityPong
2. Click on "Releases" to find the latest release of the game.
3. Scroll down to "Assets" and download the release ZIP file for your platform.
4. Extract the ZIP file to your desired location.
5. Double click the extracted game labeled PongUnity.exe (on Windows) or PongUnity.app (on macOS) or PongUnity.x86_64 (on Linux) to launch the game.

### Permissions On Mac

If you encounter permission issues when trying to run the game on macOS, you may need to allow the application to run from the Security & Privacy settings:

1. Open "System Preferences" and go to "Security & Privacy".
2. Under the "General" tab, look for a message about the blocked application.
3. Click "Open Anyway" to allow the application to run.

### Controls

- Player 1 (Left Paddle):
  - Move Up: W
  - Move Down: S

- Player 2 (Right Paddle):
  - Move Up: Up Arrow
  - Move Down: Down Arrow

### Buttons

Main Menu:

- Start Game: Play (From main menu)
- Instructions: Instructions Button (From main menu)
- Quit Game: Quit (From main menu)

Game Screen:

- Pause Game: [esc] (From game screen)
- Instructions: Instructions Button (From game screen)
- Exit Game: Exit Button (From game screen)

### Instructions

- Use the W and S keys to move the left paddle up and down.
- Use the Up and Down Arrow keys to move the right paddle up and down.

### Objective

- Score points by getting the ball past your opponent's paddle.
- Scoring is unlimited and the game continues until players decide to quit.

#### If you want to join the production team

### Cloning the Repository

1. Open a terminal or command prompt.
2. Navigate to the directory where you want to clone the repository.
3. Run the following command to clone the repository:

   ```bash
   git clone https://github.com/cbalesohay/UnityPong.git
   ```

4. Navigate into the cloned repository folder:

   ```bash
   cd UnityPong
   ```

### Install Unity Hub + Specific Unity Version

1. Download and install Unity Hub from the official Unity website: https://unity.com/download
2. Open Unity Hub and sign in with your Unity account.
3. Click on the "Installs" tab and then "Add" to install the Unity version specified for this project (6.5 6000.5.6f1).
4. Once the installation is complete, you can open the project through Unity Hub by clicking on the "Projects" tab and then "Add" to locate the project folder.

### Adding + Opening the Project

1. Open Unity Hub.
2. Click on the "Add" button to add the UnityPong project you just downloaded.
3. Then, select the UnityPong folder to open the project in Unity.
