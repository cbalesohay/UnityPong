# Unity Pong

# Unity Version: 6.5 6000.5.6f1

### Downloading the Game:

1. Visit the Unity Pong repository on GitHub. https://github.com/cbalesohay/UnityPong
2. Click on "Releases" to find the latest release of the game.
3. Scroll down to "Assets" and download the release ZIP file for your platform.
4. Extract the ZIP file to your desired location.
5. Double click the extracted game labeled PongUnity.exe (on Windows) or PongUnity.app (on macOS) or PongUnity.x86_64 (on Linux) to launch the game.

### Controls

- Player 1 (Left Paddle):
  - Move Up: W
  - Move Down: S

- Player 2 (Right Paddle):
  - Move Up: Up Arrow
  - Move Down: Down Arrow

### Buttons

Main Menu:

- Start Game: Play (From main menu)
- Instructions: Instructions Button (From main menu)
- Quit Game: Quit (From main menu)

Game Screen:

- Pause Game: [esc] (From game screen)
- Instructions: Instructions Button (From game screen)
- Exit Game: Exit Button (From game screen)

### Instructions

- Use the W and S keys to move the left paddle up and down.
- Use the Up and Down Arrow keys to move the right paddle up and down.

### Objective
- Score points by getting the ball past your opponent's paddle.
- Scoring is unlimited and the game continues until players decide to quit.
